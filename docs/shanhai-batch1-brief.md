## 批 1 = 三件事

1. **六个主动技全部改成"操作"**（含天问拉弓的输入状态机）→ 改判规格 **L163–192**、**L177–192**
2. **开局三系终极武器换成全新机制**：裂地 / 潮汐 / 天罚轮转 → **L118–143**（后三系 十日/百巫/玉璧 属批 2）
3. **解锁链 + 术语 + HUD 表达** → **L101–162**

## 六条验收标准（不通过就不算做完）

1. 合体必须要求"**该系主动技已解锁**"；缺这一条时**不得**合体。
2. 先解锁技能 → 再合体 → **技能仍可用**（消灭"合体吃掉技能"的顺序依赖）。
3. **六个终极机制两两不同**；**六个主动技两两类型不同**（位移 / 地形 / 控场 / 瞄准 / 处决 / 防御 各一个），且**没有一个是纯范围伤害**。
4. 除裂地外，终极在**玩家零输入**时也必须持续输出；裂地按"沿固定路线移动"验证。
5. 终极输出 **≥ 被它替换的四把满级武器同条件总输出的 1.5 倍**。
6. 拉弓状态机：**反向拖拽 = 拉弦**、未满蓄也发射、拖回取消不进冷却、蓄力期间移速 **×0.7**。

（完整测试清单：改判规格 **L214–233**）
