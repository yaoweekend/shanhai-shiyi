## 改什么（两系 + 两条全局）

**巫魄（灵山）**：① 蛊毒 dps 随标记层数放大（`base × (1 + 0.6 × (层数−1))`）② 巫影加直接伤害 `wraithDamage` 30 / 38 / 52 ③ 诅咒改成**只对已标记目标生效**，值为 `诅咒 + 0.12 × 层数`；通道数值：巫咸符 18%→24%、巫魄 8%→10% ④ 蛊爆 **CD 12→5**、标记寿命 **4→7 秒**、**每次只扣 1 层**（不清空）、`perStack` 55→48。

**不死魄（昆仑）**：① 玉璧环补**接触伤害** `dps` 150→320（现在完全没有伤害字段）② **以守为攻**：每 10 点当前护盾 → +3.5% 全局伤害，**上限 +35%** ③ 反弹倍率不变，定位改为"对远程强势" ④ 角色代价 `暴击率 −5%` → **`移速 −5%`**。

**六系主动技 CD**：灵 **5** / 海 10 / 天 11 / 山 **13** / 荒 **14** / 昆 **17**。

**冷却缩减**：通道语义扩展为"闪避 + 主动技共用"，**有效 CD = max(3, 基础 × (1 − 冷却缩减))**，下限 3 秒是硬要求。

（完整参数：平衡规格 **L100–148**）

## 六条验收

1. **六系清场当量**：固定种子 + 第 5 分钟兽潮档 + 60 秒 + 玩家只走固定圆形路线（零攻击输入）+ 该系 4 满级武器 / 4 被动 / 本系角色 → **最大值 ÷ 最小值 ≤ 1.15**；合体后再跑一遍同样达标。**进回归套件。**
2. 蛊爆：叠 3 层单次伤害 > 旧版 225；连爆三次各扣 1 层；第 4 次无层可扣；**不清空未消耗层数**。
3. 诅咒：未标记目标**无加成**；3 层标记 = `诅咒 + 0.36`。
4. 不死魄：**在没有任何远程怪的场景下**，其终极武器仍产生有效伤害（修复前此值为 0）。
5. 以守为攻：随护盾单调上升且**在 +35% 封顶**；冷却缩减叠满时有效 CD **≥ 3 秒**。
6. **不得回归**：六系各自可通关、终极机制两两不同、主动技类型两两不同。

（完整测试清单：平衡规格 **L157–174**）
