# 山海拾遗 · 六系平衡修订（规格增补）

## 一页速览（冷启动只读这里）

- **解决什么**：六个终极做完后，**巫魄（灵山）与不死魄（昆仑）攻击太乏力**；根因不是"数值不够"，而是**没有任何一条"六系清场能力齐平"的基线**，于是辅助/防御系自然塌陷。
- **目标基线（新增，可测）**：标准兽潮下 60 秒，**六系总伤害的最大值 ÷ 最小值 ≤ 1.15**。
- **巫魄修法（4 条）**：蛊毒 dps 随标记层数放大 · 巫影给一点直接伤害（点火）· **诅咒改为"仅对已标记者生效 + 每层追加"** · 蛊爆 **CD 12→5 秒 / 标记寿命 4→7 秒 / 每次只扣 1 层**。
- **不死魄修法（4 条）**：**玉璧环补上接触伤害**（现在整个字段表里没有伤害值）· **以守为攻**（每 10 点护盾 → +3.5% 伤害，上限 +35%）· 反弹保留为"对远程怪强势" · **角色代价从"−5% 暴击"改成"−5% 移速"**（暴击是乘性成长通道，砍它等于砍后期）。
- **主动技 CD 由"角色"决定**：灵 5（输出循环）/ 海 10（位移）/ 天 11（爆发瞄准）/ 山 13（地形）/ 荒 14（控场）/ 昆 17（翻盘保命）；**单次强度必须与 CD 成反比**。
- **冷却缩减通道扩展**：从"只作用于闪避"扩展为"闪避 + 主动技共用"，**有效 CD 下限硬性 3 秒**。
- **海魄预案**：潮汐当前有效输出明显偏低，按"环伤 ×1.7、周期 ×0.8"先调一档，再用基线复测。
- **本文件用法**：**先只读本节**；需要细节按小节局部读（`offset`/`limit`），不要全文通读。

## Problem Statement

六个终极武器都做完之后，我一上手就发现两个系**打不动怪**：

- **巫魄**（灵山）——靠标记和蛊毒打伤害，可标记叠不起来、蛊毒不痛、引爆还慢，场上的怪清不掉；
- **不死魄**（昆仑）——肉是肉，但它的终极武器**对近战怪几乎没有输出**，我只能在兽潮里站着挨打。

更糟的是，我说不清"多强才算合格"——**我没有一把尺子。** 我在改判规格里写过"终极武器 ≥ 被替换的四把满级武器的 1.5 倍"，但**那条只管一个系自己的内部换算，完全没管六系之间**。于是"辅助系""防御系"这些定位，在没有基线的环境里自然塌陷成了"弱系"。

我要的不只是"把这两个系调强"，而是**一条能防止同样的事再发生一次的尺子**。

## Solution

- **六系清场当量齐平**：标准兽潮下 60 秒，六系总伤害的最大值 ÷ 最小值 ≤ **1.15**。差异只允许出现在**方式**（直接 / 持续 / 召唤 / 反弹 / 传染），不允许出现在**总量**。
- **巫魄 = 越打越多**：标记不再只是一个易伤贴纸，而是它的**弹药**——层数越高蛊毒越痛、诅咒越强、引爆越狠；改完之后它是**前期偏弱、敌人一密就雪崩**的曲线。
- **不死魄 = 以守为攻**：护盾不只是挡伤害，**它按比例直接换算成伤害**；玉璧环本身也造成接触伤害，所以它对近战兽潮有输出，反弹则成为它对付远程的优势手段。
- **主动技的冷却由"角色"决定**：承担输出循环的技能 CD 短（蛊爆 5 秒），承担翻盘保命的技能 CD 长（不死药 17 秒），并且**单次效果强度与 CD 成反比**——玩家能一眼读出"哪个是循环、哪个是底牌"。
- **冷却缩减打通**：让"冷却"成为一条真正可构筑的轴，同时用 **3 秒下限**焊死"零 CD 刷技能"的口子。

## User Stories

1. As a **巫魄玩家**, I want 标记层数越高、蛊毒越痛, so that "我一直在叠标记"这件事本身有回报。
2. As a **巫魄玩家**, I want 巫影能打出一点直接伤害, so that 传染链能被点燃，而不是等一个永远不会来的第一滴血。
3. As a **巫魄玩家**, I want 诅咒只对**被标记的敌人**生效但威力更大, so that "我特意去打被标记的目标"是有意义的操作。
4. As a **巫魄玩家**, I want 蛊爆的冷却短到可以每 5 秒来一次, so that 它是我伤害循环的一部分，而不是偶尔开一次的烟花。
5. As a **巫魄玩家**, I want 标记活得比冷却更久, so that 我不会陷入"想爆但没标记、有标记又不能爆"。
6. As a **巫魄玩家**, I want 一次蛊爆只吃掉一层标记, so that 叠到三层可以连续引爆，而且不会把我自己的增伤一起清掉。
7. As a **巫魄玩家**, I want 场上没有标记时蛊爆不消耗冷却, so that 我不会因为空放而白白等 5 秒。
8. As a **巫魄玩家**, I want 怪越密伤害越高, so that 后期的兽潮变成我的顺风局。
9. As a **不死魄玩家**, I want 玉璧环本身就造成伤害, so that 面对近战兽潮我也有输出，而不是只能挨打。
10. As a **不死魄玩家**, I want 护盾越多、伤害越高, so that "堆肉"直接换来输出，"我越肉越能打"的直觉成立。
11. As a **不死魄玩家**, I want 反弹弹幕仍然是它的招牌, so that 面对远程怪我是全游戏最强的那个。
12. As a **不死魄玩家**, I want 我的角色代价不再是"砍暴击", so that 我的成长上限不被角色本身封死。
13. As a **不死魄玩家**, I want 一个 17 秒的救命键, so that 它是底牌而不是循环。
14. As a **海魄玩家**, I want 潮汐的输出别再垫底, so that 海经不是"只有位移能用"的系。
15. As a **玩家**, I want 六个系的清场速度差不多, so that 我选哪个系是因为我想怎么玩，而不是因为哪个强。
16. As a **玩家**, I want 每个系的强弱出现在**方式**上而不是**总量**上, so that 换系玩是换手感，不是换难度。
17. As a **玩家**, I want 主动技的冷却长短一眼能读出它的用途, so that 我不需要看说明就知道哪个该常按、哪个该留着。
18. As a **玩家**, I want 冷却缩减能作用在主动技上, so that "技能转得快"成为一条能构筑的路线。
19. As a **玩家**, I want 冷却有下限, so that 构筑再极端也不会变成"站着刷技能"。
20. As a **玩家**, I want 巫魄前期偏弱、后期爆炸, so that 它有一个值得熬过去的成长曲线。
21. As a **玩家**, I want 不死魄的肉直接变成输出, so that 防御系的玩法不是"无聊但活着"。
22. As a **玩家**, I want 蛊爆在密集怪群里特别爽, so that 它有一个明确的"最佳使用时机"。
23. As a **实现者**, I want 一条可测的六系基线（最大值 ÷ 最小值 ≤ 1.15）, so that 我调数值时有客观依据，不靠手感。
24. As a **实现者**, I want 基线测试的**场景参数被写死**（种子、兽潮档位、走位路线、配装）, so that 我的测量可复现、可回归。
25. As a **实现者**, I want 明确区分"改数值"与"改机制", so that 我知道哪些是一行参数、哪些要动逻辑。
26. As a **实现者**, I want 标记层数、寿命、冷却三者的新关系被写清楚, so that 我不会只改一个参数就以为修好了。
27. As a **实现者**, I want 诅咒的条件化改写点被点名, so that 我不会漏掉伤害结算那一处。
28. As a **实现者**, I want "以守为攻"的换算公式与上限, so that 它不会随护盾堆叠失控。
29. As a **实现者**, I want 海魄的预案数值, so that 我不必自己猜该加多少。
30. As a **维护者**, I want 这次修订明确标注是对两份既有规格的补丁, so that 后人知道基线是后补的、不是当初漏写。
31. As a **维护者**, I want 基线测试进回归套件, so that 以后加内容时同样的塌陷会被立刻测出来。
32. As a **维护者**, I want 六系 CD 与角色写进一张表, so that 以后新增系时有模板可依。

## Implementation Decisions

### 0. 术语（本文新增）

| 术语 | 含义 |
|---|---|
| **清场当量** | 标准兽潮下固定时长内造成的总伤害，用于横向比较六系强弱 |
| **标记层数** | 单个敌人身上的蛊毒层数（1~3），决定蛊毒 dps、诅咒加成与引爆伤害 |
| **以守为攻** | 昆仑的换算规则：护盾按比例直接换算为全局伤害加成 |
| **技能角色** | 主动技承担的职责分类（输出循环 / 位移 / 爆发瞄准 / 地形 / 控场 / 翻盘保命），**CD 由角色决定** |

### 1. 目标基线（本次修订的根本，必须写成测试）

**六系清场当量齐平**。测试场景参数（**内联契约**，比散文更精确）：

| 项 | 值 |
|---|---|
| 随机种子 | 固定值，可复现 |
| 兽潮档位 | 第 5 分钟难度档的敌人配置 |
| 时长 | 60 秒 |
| 玩家行为 | **零攻击输入**，沿固定圆形路线移动（半径恒定、角速度恒定）——保证"需要移动的机制"（裂地）与"常驻机制"可比 |
| 配装 | 该系 4 把武器全部满级 + 该系 4 件被动 + 该系角色；其余槽位留空 |
| 指标 | 60 秒内造成的总伤害 |
| **通过条件** | **六系最大值 ÷ 最小值 ≤ 1.15** |
| 补充 | 合体后（终极武器就位）再跑一遍，同样 ≤ 1.15 |

### 2. 巫魄（灵山）修法

| # | 改动 | 类型 |
|---|---|---|
| ① | **蛊毒 dps 随标记层数放大**：`plagueDps = base × (1 + 0.6 × (层数 − 1))`，3 层 = **2.2 倍**。写入时按**当前层数**重算（而不是取历史最大值） | 机制 |
| ② | **巫影给直接伤害**：新增字段 `wraithDamage`，建议 Lv1 **30** / Lv3 **38** / Lv5 **52**（巫影现在**完全不造成伤害**，导致传染链点不着火） | 数值 |
| ③ | **诅咒条件化**：伤害结算处由 `× (1 + 全局诅咒)` 改为 **仅当目标已标记时生效**，加成值 = `诅咒 + 0.12 × 层数`（层数上限 3，即最多再 +0.36）。同时通道数值上调：被动「巫咸符」18% → **24%**，角色「巫魄」8% → **10%** | 机制 |
| ④ | **三参数解锁**：蛊爆 CD **12 → 5 秒**；标记寿命 **4 → 7 秒**；蛊爆**每次只消耗 1 层**（伤害仍按消耗前的层数计算）。`perStack` 建议 55 → **48**（因为现在可以连爆三次，避免总量失控） | 数值 |

- **保留**：场上没有标记时蛊爆**不进冷却**（现有实现已正确，别改坏）。
- **目标形态**：单目标"叠 3 层 → 连爆 3 次"的合计伤害应高于旧版单次引爆；**群体输出必须显著高于旧版**（这是巫魄存在的理由）。

### 3. 不死魄（昆仑）修法

| # | 改动 | 类型 |
|---|---|---|
| ① | **玉璧环补接触伤害**：给终极武器增加伤害字段，建议 Lv1 `dps` **150** → Lv5 **320**（tick 0.3）。**现在它的字段表里只有半径、转速、反弹倍率、护盾——没有任何伤害值**，所以对近战怪输出为零 | 机制 |
| ② | **以守为攻**：新增全局换算 **每 10 点当前护盾 → +3.5% 全局伤害，上限 +35%**（Lv5 护盾上限 82 → 约 +28.7%） | 机制 |
| ③ | **反弹定位**：`reflectMul` 215→405 **保持不变**，但它的定位从"唯一输出"改为"**对远程怪的强势手段**"（近战兽潮由 ① 负责） | 定位 |
| ④ | **角色代价改写**：`不死魄` 的修正从 `{ 减伤 +8%, 暴击率 −5% }` 改为 `{ 减伤 +8%, **移速 −5%** }`。理由：**暴击率是乘性成长通道，砍它等于直接封死后期上限**，而它同时还有一整套防御向被动——双重惩罚。改为移速后仍是"一正一负、幅度 ≤10%"，但**劣势不再落在输出上限上** | 数值 |

### 4. 六系主动技 CD（由角色决定）

| 系 | 主动技 | 技能角色 | 旧 CD | **新 CD** | 单次强度定位 |
|---|---|---|---|---|---|
| 灵山 | 蛊爆 | **输出循环** | 12 | **5** | 弱（靠频率与叠层滚雪球） |
| 海经 | 化潮 | 位移 | 10 | **10** | 中（逃命兼清路） |
| 天问 | 拉弓巨箭 | 爆发瞄准 | 11 | **11** | 强（一发一条线） |
| 山经 | 立岩 | 地形 / 自保 | 14 | **13** | 中（造安全圈） |
| 大荒经 | 锁天 | 控场 | 15 | **14** | 中（把危险区变安全区） |
| 昆仑 | 不死药 | 翻盘保命 | 18 | **17** | 极强（一次救命） |

**规则**：**单次效果强度必须与 CD 成反比**。若将来新增技能，先定它的"角色"，再按上表定 CD。

### 5. 冷却缩减通道扩展

- 通道 `dodgeCooldown`（现中文名「闪避冷却」）语义扩展为 **「技艺冷却」：同时缩短闪避与主动技的冷却**（通道 id 不变，避免存档与内容表迁移）。
- 有效冷却公式：**`有效CD = max(3, 基础CD × (1 − 冷却缩减))`**。
- **下限 3 秒是硬要求**：否则蛊爆 5 秒吃满缩减后会变成"站着刷技能"。
- 现有提供该通道的被动（灵山「灵山雾」）数值**不变**，但它现在**同时缩短主动技冷却**——灵山因此获得"技能转得最快"的系身份。

### 6. 海魄（潮汐）预案

当前潮汐"每次环扫伤害 52→98 × 2 道环 ÷ 周期 1.24~1.5 秒"的有效输出明显低于其它终极（落雷每秒 2~3 次、十日光束 14 道、裂地持续轨迹）。

**先调一档**：环伤 52→98 提升为 **90→170**；周期 1.5→1.24 缩短为 **1.20→0.95**；并确认**内 / 外两道环对同一敌人各结算一次**。预估有效输出约 ×2.1。

**不承诺精确数值**：调完用 §1 的基线复测，若仍低于下限则继续加，**以基线为准而不是以本文档的估算为准**。

### 7. 已核实的既有实现事实（避免返工）

- 主动技已按 **`type` 分派**（`terrain / dash / control / execute / defense / aim`），骨架与改判规格一致，**不需要重构**。
- 蛊爆在"场上无标记"时**已正确地不进冷却**。
- 标记寿命与"死亡时爆毒"共用 `markUntil` 字段；**修改寿命时注意清理逻辑不要一起改坏**（代码里已有一处关于"残留标记误触发"的注释与清理）。

## Testing Decisions

**原则**：只测外部行为（给定场景与输入，结果如何），不断言内部函数组织结构。

1. **六系清场当量基线（新增，最重要）**：按 §1 的内联契约跑六系，断言 **最大值 ÷ 最小值 ≤ 1.15**；合体后再跑一遍，同样 ≤ 1.15。**必须进回归套件**——这是防止"下次加内容又塌一次"的唯一保险。
2. **巫魄循环**：① 同一目标叠 3 层后单次蛊爆伤害 > 旧版单次（60 + 55×3 = 225）；② 连续三次引爆各扣 1 层，第 4 次无层可扣；③ 引爆**不会**把未消耗的层数清零；④ 标记寿命 7 秒内可完成"叠层 → 引爆"。
3. **诅咒条件化**：对**未标记**目标无诅咒加成；对 3 层标记目标的加成 = `诅咒通道 + 0.36`。
4. **巫影点火**：巫影能独立击杀最弱敌人（证明传染链能自行启动）。
5. **不死魄对近战兽潮**：**在一只远程怪都不存在的场景下**，其终极武器仍产生有效伤害（这是修复前为零的场景，必须有断言）。
6. **以守为攻**：伤害加成随护盾单调上升，**且在 +35% 处封顶**。
7. **CD 与下限**：六系 CD 与 §4 表一致；冷却缩减叠满时有效 CD **不低于 3 秒**（含蛊爆）。
8. **冷却通道联动**：提供该通道的被动**同时**缩短闪避与主动技冷却。
9. **回归**：六系各自可通关（既有断言）、终极机制两两不同、主动技类型两两不同——这三条**不得因本次调整而失效**。

**先例**：沿用既有的 `test/all.mjs` 多套件编排与固定种子无头模拟；本次新增的"清场当量"套件应复用同一套无头场景构造方式。

## Out of Scope

- 不改六系**基础武器与被动的机制**（本次只动巫魄、不死魄两系的指定项与 CD）
- 不改终极武器的**弹道几何与视觉**（玉璧只加伤害字段，不改环的形态）
- 不改槽位数（武器 4 / 被动 5）、不改血统与合体的触发条件
- 不做新的神系、不做终极变异形态、不做终极专属被动卡池
- 不做联机 / 排行榜 / 云存档 / 广告（**游戏仍然严格不联网**）

### 这次修订是对两份既有规格的补丁

1. `specs/shanhai-survivors.md`（总规格）——它定义了六系，但**没有定义"六系之间必须一样强"**。
2. `specs/shanhai-ultimate-rework.md`（改判规格）——它写了"终极输出 ≥ 被替换四把武器的 1.5 倍"，**那是一条系内换算，不是系间基线**。

**基线是这次补上的**。写下这一点，是为了让后人知道"基线后补"是刻意的，而不是当初漏写没人管。

### 诊断证据（本次修订的依据）

- **不死魄的终极武器字段表里没有任何伤害值**（只有 `orbit / band / spin / rings / reflectMul / shieldCap / shieldRegen`）→ 对近战怪输出结构性为零。
- **巫魄的终极武器里巫影 `wraiths` 不造成伤害**（只有 `markStacks`）→ 传染链依赖"先杀敌"，而杀敌又依赖伤害，**自我循环无法点火**。
- **标记寿命 4 秒 vs 蛊爆冷却 12 秒**（`markUntil = elapsed + 4000`、`cd: 12`）→ 两个参数互锁，玩家大部分时间处于"想爆没标记、有标记不能爆"。
- **蛊爆清空全部标记**，而它同时是巫魄唯一的易伤来源 → 自己拆自己的台（第 ④ 条的"只扣一层"就是为这个）。
- **不死魄的角色修正含"暴击率 −5%"**，而暴击是乘性成长通道 → 角色本身封死上限，且与"一整套防御被动"构成双重惩罚。
- **两系的被动池里没有任何乘性进攻通道**（灵山只有诅咒与召唤强度；昆仑全是防御）→ 即使白值不差，**成长曲线依然落后**。
- 反证：**大荒经的武器白值在六系里最低，但没人觉得荒魄弱**——因为它的终极武器每秒落雷 2~3 次。**这说明决定手感的是"终极武器 + 被动乘数"，而不是武器白值。**

### 改数值 vs 改机制的清单（实现时别搞混）

- **改数值**：巫影伤害、诅咒通道数值、蛊爆 CD / `perStack`、标记寿命、玉璧 dps、以守为攻系数与上限、六系 CD 表、潮汐环伤与周期。
- **改机制**：蛊毒 dps 随层数重算、诅咒条件化、蛊爆"只扣一层"、玉璧接触伤害判定、以守为攻的换算、冷却缩减作用于主动技。

### 与既有实现的交叉点

- `activeSkillUnlocked` 的**持久化**（改判规格要求）与本次 CD 调整**互不影响**，但两者都改同一批数据，实现时按改判规格 §4 的顺序做。
- 本次改动**不触碰** `slots.weapons` 塌缩语义、不触碰 `checkUltimateFusion` 的前置条件。
