# 山海拾遗 · 批 1 实现

手机端弹幕天堂肉鸽。**纯静态网页游戏**：HTML + Canvas 2D + 原生 JavaScript，零依赖、零构建期框架、严格不联网。

规格来源：`../规格工坊/specs/shanhai-survivors.md`（本目录是它的实现，规格只描述"要什么"，这里描述"怎么跑"）。

---

## 跑起来

```bash
# 开发/自测（需要 HTTP 服务，因为用了 ES Module）
node tools/serve.mjs 8080
# 浏览器打开 http://127.0.0.1:8080/
```

正式分发不需要任何服务端：把整个 `shanhai/` 目录丢到任意静态托管（或直接双击打开时用支持 `file://` 模块加载的环境），
因为代码里**没有任何 `fetch`/`XHR`/`WebSocket`**——`tools/serve.mjs` 只是本地开发用的静态文件服务器。

Android 侧：先侧载到真实设备验证能不能跑起来，再考虑套壳（批 1 不做套壳）。

## 批 1 改判：主动技 = 操作，终极武器 = 全新机制

这一轮不是加内容，是**改判职责分工**（规格 `../规格工坊/specs/shanhai-ultimate-rework.md`）：

- **终极武器 = 自动化火力**（不要求任何操作；唯一例外是裂地要求"移动"这个位置行为）；
  **主动技 = 玩家施加的操作**，伤害只是副产品。
- **六个主动技两两类型不同**：立岩（地形）/ 化潮（位移）/ 锁天（控场）/ 拉弓巨箭（瞄准）/ 蛊爆（处决）/ 不死药（防御）。
  批 1 只有天问（拉弓）用非点按手势，其余五系先点按。
- **开局三系终极换成三种全新判定形状**：裂地（轨迹型）/ 潮汐（往返环）/ 天罚轮转（移动轰炸带）。
  后三系（十日 / 百巫 / 玉璧）仍走 `kind:'aura'` 占位，**属批 2**。
- **解锁链**：本系武器满级 → 血统（满级 + 指定被动）→ 集齐 3 个同系超武解锁该系主动技 →
  **4 把满级 + 4 件指定被动 + 该系主动技已解锁** → 合体。
  主动技解锁状态**达成即持久化**（`world.activeSkillUnlocked`，进存档），跨合体保持可用 ——
  不写成"每帧从武器槽里数超武数量"（合体会把 4 把塌缩成 1 把，那种写法必然失效）。
- **终极武器从 Lv1 起步、可升到 Lv5**，Lv3 / Lv5 是质变点；HUD 上是 **1 格终极 + 3 格纯金色锁定格**
  （锁定格刻意不画被合掉武器的微缩图标 —— 它们已经被消耗了）。
- **拉弓状态机**（内联契约）：按下进蓄力 → 反向拖拽瞄准（方向 = `normalize(p0 − p1)`，箭向反方向飞）→
  松手发射（未满蓄也发射）；拖回按下点再松手 = 取消、**不进冷却**；蓄力期间移速 **×0.7**；
  满蓄时准星变金 + 音效上扬。
- **平衡硬要求**：终极武器的每秒输出 ≥ 被它替换的四把满级武器同条件总输出的 **1.5 倍**
  （合体是不可逆的消耗，换回来的必须明显更赚）。
  实测（`test/batch1-rework.mjs` 第 5 节，固定种子 20260926 + 固定靶场）：Lv1 **1.72× / 1.93× / 1.85×**。
- **术语钉死**：血统 / 超武 / 主动技 / **合体** / 终极武器。**"融合"是废弃词**，用户可见文案里不得再用。

### 命名规则（重要，别再踩）

- 武器 id **自带 `w_` 前缀**：`w_shoujia`。
- 所以图标槽位 id = `'icon_' + 武器id` = **`icon_w_shoujia`**；
  投射物槽位 id = `'proj_' + 武器id.replace(/^w_/,'')` = **`proj_shoujia`**。
- 写成 `'icon_w_' + id` 会拼出不存在的 `icon_w_w_shoujia` —— 渲染层不会报错，
  只会**静默回退到一张错的占位图**，所以有 `tools/verify-icon-slots.mjs` 守着。
- 角色/敌人槽位是 `char_<角色id>` / `enemy_<种类id>`；Boss 是 `boss_xiangliu`。
- DOM 里所有屏幕 id 都是 `screen-<name>`（含 `screen-hud`），`UI.el()` 依赖这个前缀。

## 怎么替换正式美术（规格 §12）

1. 把图片放进 `assets/`（例如 `assets/art/char_shanpo.png`）。
2. 在 `src/assets/manifest.js` 里给对应槽位填 `file`（以及许可 / 来源 URL / 下载日期）。
3. **不改任何游戏逻辑**：逻辑只引用槽位 id，缺失文件时自动回退到程序生成的占位图。
4. 设置里打开「开发模式：占位图标注槽位 id」，就能在游戏里直接看到每个槽位的 id。

`关于 / 许可` 页会自动列出槽位总数与"已替换/程序生成"的数量，方便核对替换进度。

## 已知取舍与偏离（实现期做的决定，写在这里而不是改规格）

0. **触碰伤害必须被节流**（重要）：接触伤害有自己的轮空档（500ms，子弹/爆炸仍是 700ms）。
   一屏 300 只怪时，如果每只都能独立打你，玩家会在几秒内被"叠加的接触伤害"融化——那不是难度，是不讲道理。
   同屏密度、接触伤害成长（+3%/档）、基础血量（130）都是围绕这条重新标定的。
1. **`dr` 硬上限取 0.79、暴击率 0.99**：规格要求"上限必须 < 80% / < 100%"，取严格小于的值以便自检断言。
2. **等级韧性 + 局内血量成长**：受创结算里额外乘一层 `(1 − min(0.35, (等级−1)×1.5%))`，
   同时每升一级 +6 血上限（`PLAYER_BASE.hpPerLevel`）。两者都是**乘法/加法在通道之外的局内成长**，
   不会叠加到 24 通道里的"减伤"上，因此 80% 上限永不被突破。
   注意这与规格 §8 的"解锁不给数值加成"不冲突——那条约束的是**局外**解锁，这里是局内成长。
3. **落雷预警**：`荒雷落顶` 的预警圈在 `delay` 期间是纯视觉，实体占用 zones 池；命中判定在 delay 结束时一次性结算。
4. **掉落池满时合并**：池满不是丢弃经验，而是把价值并入最老的掉落物——丢经验会直接掐断成长曲线。
5. **自爆与冲锋有预警**：傒囊点燃 0.45 秒引信、强良蓄力 0.35 秒（画面上都有明确提示）。
   规格没写，但"看不见就打到你"的自爆是不公平的失败来源。
6. **"主动道具"按钮目前是灰的**：规格 §6 / US 21 要求屏幕上有两个按钮，批 1 只实现了闪避；
   主动道具系统未在规格里定义内容，保留占位按钮与命中区。
7. **音效全部为 WebAudio 合成**（零素材、零许可风险）。规格 §14 要求"CC0 素材打底 + WebAudio 动态变调"，
   批 1 只做了后者；正式音效到位后在 `manifest.js` 里登记文件即可替换。
8. **Boss 战的 12:00 收束**：非无尽模式下 12:00 仍未击杀相柳则按失败结算，避免无限拖时间。
9. **无尽模式只在通关后出现**（规格 §7：通关后可选）。

## Android 安装包（套壳）

规格 §16 把套壳归到「随时」批次，所以它不属于批 1。已经做好了，重出包一条命令：

```powershell
# 在 D:\吴琦姜也 下运行
powershell -NoProfile -ExecutionPolicy Bypass -File build-shanhai-apk.ps1
# 产出：D:\吴琦姜也\山海拾遗-v0.1.0.apk（约 105 KB，自签名）
```

壳工程在 `tools/shanhai-build/`，要点：

- **零第三方依赖**（不含 AndroidX），所以 Gradle 能纯离线构建。
  本地资源拦截、MIME 判定、沉浸式全屏都用平台 API 自己写（`app/src/main/java/.../MainActivity.java`）。
- 页面从**内部虚拟域名** `https://appassets.androidplatform.net/assets/` 加载，由 App 自己从 APK 的
  assets 直接返回内容，**请求不离开设备**。用这个域名（而不是 `file://`）是为了让 `localStorage`
  落在正常的 origin 上——**断点续局、图鉴、试炼进度全靠它**。
- manifest 里唯一声明的权限是 `INTERNET`，理由就在上面那条（WebView 内部加载层需要）。
  游戏代码本身没有任何网络调用，由 `tools/check.mjs` 守。
- 包名 `com.wuqijiangye.shanhai`，版本码 1 / 版本名 0.1.0，`minSdk 26` / `targetSdk 35`，
  纯 Java + 资源、**没有任何 native 库**，因此 32/64 位全兼容。
- `assembleDebug` 会产出包名带 `.verify` 后缀的**验证用变体**（可调试、可与正式包共存、
  不对外分发），用于在真机上用 adb 检查 localStorage 是否落盘。
