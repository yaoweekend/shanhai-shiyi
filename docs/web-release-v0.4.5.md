# 《山海拾遗》v0.4.5 网页版

游玩地址：https://shanhai-shiyi-v045.jammykiwi512.chatgpt.site/

把上面的链接发到 QQ 群即可。游戏适合手机横屏；如果 QQ 内打开后显示异常，可从右上角选择“在浏览器中打开”。

## 版本来源

网页压缩包是从已发布的 `dist/山海拾遗-v0.4.5.apk` 中提取的 104 个资源，与 APK 中的同名资源逐个校验一致。当前工作区尚未发布的山魄／海魄联动样板没有进入此网页版。

网页版使用浏览器的本地存储保存进度。不同浏览器、不同网址与 Android 安装包之间不会自动同步存档；后续更新应沿用同一网址。

## 本地预览与部署

解压后把包含 `index.html` 的目录作为静态网站根目录，使用支持 ES Modules 的 HTTP 服务访问。不能直接双击 `index.html` 以 `file://` 打开。

本地压缩包：`dist/山海拾遗-v0.4.5-网页版.zip`。

已在 960×540、800×360 横屏浏览器检查主页、长内容页、战斗、暂停、保存续局、结算和无尽主动结算。尚未在 QQ 内置浏览器及多款实体手机上逐一验证。
