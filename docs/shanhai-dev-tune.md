# 山海拾遗 · 调参面板（测试版）规格

## 一页速览（冷启动只读这里）

- **一句话**：一个只在开发/测试包里存在的**实时调参浮层**（`?dev=tune`），让你在真机上直接改配装、怪物、时间、世界参数，**不用重开一局玩到后期**。
- **入口**：`?dev=tune`；支持组合（`?dev=ultimate,tune`）；测试包里**长按暂停键 2 秒**也能开关面板（免重新打包）。
- **五组控件**：玩家 / 配装 / 怪物 / 时间 / 世界 + 一组**只读诊断**（FPS、实体数、池使用率、tier、seed）。
- **一键预设**：满级配装 · 一键合体（自动补齐前置）· **跳到指定局内时间**（含按档位补一波怪）· 跳到 Boss 前 · 立即召唤 Boss · 无敌 · 时间缩放 0.25×~4×。
- **配置进 URL**：整份配置可导成一个可分享的 URL；**你甩我一条 URL，我打开就是同一状态**——这是最准的复现手段，也最省 token。
- **三条硬约束**：① 面板入口**不得进入正式包**（静态检查守住）；② 调参**只作用于当前这一局，不写存档**；③ 面板**不得联网**（沿用既有的无网络守卫）。
- **本文件用法**：较薄（≈200 行），**可直接整体读**，不需要单独开工卡。

---

## Problem Statement

调平衡的时候，我被三件事卡住：

1. **验证一个系要手动玩到后期。** 我想看"山魄第 9 分钟还行不行"，就只能真的打 9 分钟。想对比六个系，就是六局 10 分钟。**我大部分时间花在"走到那个状态"上，而不是在调参数。**
2. **怪的种类和数量改不了。** 我想知道"如果场上没有远程怪，不死魄够不够"，做不到；我想试"同屏怪数量翻倍会不会掉帧"，也做不到。
3. **报 bug 只能靠嘴描述。** 我遇到一个现象，描述给 AI 时它得自己猜、自己复现；**一旦它复现不出来，就是一轮又一轮的来回**——既慢又费 token。

我要的是一个**能在真机上当场改参数**的工具，把"走过去"这件事变成"点一下"。

## Solution

一个只在开发/测试包里存在的**实时调参浮层**：

- 打开 `?dev=tune`（或测试包里长按暂停键 2 秒）就出现一个可折叠的半透明面板，**按钮和滑杆按真机手指尺寸做**；
- 面板分五组 + 一组只读诊断：**玩家**（生命/无敌/伤害倍率/移速）· **配装**（4 个武器槽与等级、5 个被动槽、一键满级）· **怪物**（5 种敌人逐个开关、数量与生成速率、生命与速度倍率、精英频率、`from` 出现时间）· **时间**（跳到指定局内时间、时间缩放、暂停、跳到 Boss 前、立即召唤 Boss）· **世界**（种子、掉落与经验倍率）· **诊断**（FPS、实体计数、对象池使用率、当前难度档、种子）；
- **一键预设**把最常用的动作变成一次点击：满级配装、一键合体、跳到第 9 分钟、跳到 Boss 前；
- **整份配置可导成一个 URL**，别人打开就是同一个状态。

**它只影响你当前这一局**：不写存档、不进正式包、不联网。

## User Stories

1. As a **调平衡的人**, I want 一键把某系 4 把武器升到满级并配齐被动, so that 我不用打 9 分钟就能看到后期状态。
2. As a **调平衡的人**, I want 一键合体（自动补齐"该系主动技已解锁"这个前置）, so that 我按下去就真的合体，而不是按了没反应。
3. As a **调平衡的人**, I want 把局内时间直接跳到第 9 分钟, so that 我能立刻看后期。
4. As a **调平衡的人**, I want 跳时间的同时按目标档位补一波怪, so that 跳过去之后场上不是空的。
5. As a **调平衡的人**, I want 直接跳到 Boss 前, so that 我能在 10 秒内反复测 Boss 战。
6. As a **调平衡的人**, I want 立即召唤 Boss, so that 我不用等它自己出来。
7. As a **调平衡的人**, I want 逐个开关 5 种敌人, so that 我能测"没有远程怪时某个系还行不行"。
8. As a **调平衡的人**, I want 调每种敌人的出现时间（`from`）, so that 我能试"远程怪提前到第 2 分钟"。
9. As a **调平衡的人**, I want 调怪物数量倍率与生成速率, so that 我能试更密的兽潮。
10. As a **调平衡的人**, I want 调怪物的生命与速度倍率, so that 我能单独测"血量墙"和"速度墙"。
11. As a **调平衡的人**, I want 调精英出现频率, so that 我能测精英密度对难度的影响。
12. As a **调平衡的人**, I want 无敌开关, so that 我能只看输出、不被死亡打断。
13. As a **调平衡的人**, I want 伤害倍率滑杆, so that 我能快速试"输出翻倍会怎样"。
14. As a **调平衡的人**, I want 移速调整, so that 我能试走位空间的影响。
15. As a **调平衡的人**, I want 时间缩放 0.25×~4×, so that 我能慢放看清弹幕、或快进看后期。
16. As a **调平衡的人**, I want 暂停, so that 我能停下来读数字。
17. As a **调平衡的人**, I want 4 个武器槽的下拉 + 等级滑杆, so that 我能拼出任意配装组合。
18. As a **调平衡的人**, I want 5 个被动槽的下拉, so that 我能测任意被动组合。
19. As a **调平衡的人**, I want 换种子并重开, so that 我能排除"这局运气好"的干扰。
20. As a **调平衡的人**, I want 调掉落与经验倍率, so that 我能跳过"攒资源"阶段直接测构筑。
21. As a **调平衡的人**, I want 看到 FPS 与实体计数, so that 我能立刻判断掉帧是不是数量问题。
22. As a **调平衡的人**, I want 看到对象池使用率, so that 我能发现池是不是快满了（性能问题的最常见来源）。
23. As a **调平衡的人**, I want 看到当前难度档与种子, so that 我报问题时能把环境说清楚。
24. As a **调平衡的人**, I want 把这局的状态导成 JSON, so that 我能把"某个后期状态"完整地交给别人。
25. As a **调平衡的人**, I want 把整份配置导成一个 URL, so that 别人打开就是同一状态，**不用我解释**。
26. As a **调平衡的人**, I want 面板可以折叠成一个小圆点, so that 它不挡我的视野。
27. As a **调平衡的人**, I want 面板在手机上按钮够大, so that 我能在真机上单手操作它。
28. As a **调平衡的人**, I want 面板不挡摇杆、闪避、主动技的命中区, so that 开着面板也能正常玩。
29. As a **调平衡的人**, I want 调参只影响当前这一局、不写存档, so that 我的真实解锁进度不会被污染。
30. As a **玩家/发布方**, I want 正式包里绝对没有面板入口, so that 我不能靠它作弊、发布版也不会暴露调试功能。
31. As a **实现者**, I want 面板入口的守卫写进静态检查, so that 以后重构不会不小心把它带进正式包。
32. As a **实现者**, I want 配置串有版本号, so that 以后加了新字段也不会把老配置串读错。
33. As a **实现者**, I want 时间跳转的语义被写死（设时间 + 重算难度档 + 补一波怪 + 重置刷怪计时）, so that 它不会只改一个数字然后留下一个空场。
34. As a **实现者**, I want 时间缩放作用于模拟步长而不是渲染帧率, so that 物理与判定不会因为缩放而失稳。
35. As a **维护者**, I want 这个面板只在开发包里存在, so that 正式包体积与行为都不受影响。

## Implementation Decisions

### 0. 术语

| 术语 | 含义 |
|---|---|
| **调参面板** | 只在开发/测试包中存在的实时参数浮层 |
| **预设** | 一次点击即可把游戏置入某个常用状态的按钮（满级、合体、跳到某时间……） |
| **配置串** | 把整份面板配置序列化成的一段紧凑文本，可放进 URL 或本地存储 |

### 1. 入口与生命周期

- **入口**：URL 参数 `?dev=tune`。**支持组合**：`?dev=ultimate,tune`（逗号分隔，解析成一个集合），因为"开局直接合体 + 又能调参"是最常用的组合。
- **真机快捷入口**：当 `dev` 参数非空时，**长按暂停键 2 秒**开关面板——这样在测试包里改入口参数不需要重新打包。
- **默认关闭**：进入游戏后面板是收起的，只显示一个可拖动的小圆点。
- **配置记忆**：面板配置在本地记忆（刷新/重进恢复上次的配置），但**面板不会因此自动打开**。
- **作用域**：所有改动**只作用于当前这一局**。**严禁写入存档**（不得触碰最高分、图鉴、试炼进度、解锁状态、未完成的一局）。
- **不得联网**：沿用既有的无网络守卫。

### 2. 面板形态

- 可折叠浮层：**展开**（分组的控件列表）↔ **收起**（一个可拖动的小圆点）。
- **触屏优先**：按钮与滑杆按真机手指尺寸设计（最小可点区域显著大于桌面习惯；参照现有触控布局的命中半径量级）。
- **不得遮挡触控区**：面板默认停在**上方区域**，且必须避开摇杆触发区、闪避与主动技的命中区；安全区（刘海/圆角）由现成的安全区换算统一处理，不另写一套。
- **逻辑像素布局**：沿用游戏的逻辑分辨率与等比缩放，不按物理像素写死。
- **视觉**：半透明深色底 + 高对比文字，**不与游戏内 UI 争夺注意力**。

### 3. 控件清单（五组 + 诊断）

**A. 玩家**：生命值（当前/上限）· **无敌**开关 · **伤害倍率**滑杆 · **移速**滑杆 · 护盾值 · 经验等级 ±（或"一键升级"）

**B. 配装**：4 个武器槽（下拉选武器 + 等级滑杆）· 5 个被动槽（下拉）· **一键满级本系配装** · **清空配装**

**C. 怪物**：
- **5 种敌人逐个开关**（按敌人 id：山魈 / 毕方 / 化蛇 / 傒囊 / 强良）；快捷"全开 / 全关 / 只留近战"
- 每种敌人的 **`from` 出现时间**（可把远程怪提前或推后）
- 每种敌人的 **`weight` 刷怪权重**
- **全局**：数量倍率 · 生成速率倍率 · 生命倍率 · 速度倍率 · **精英出现频率** · 难度档 `tier` 手调（跳过"每 2 分钟一档"）
- 精英词缀：开关 / 指定

**D. 时间**：当前局内时间显示 · **跳转到指定时间** · **时间缩放**（0.25×/0.5×/1×/2×/4×）· **暂停/继续** · **跳到 Boss 前** · **立即召唤 Boss**

**E. 世界**：随机种子（显示 + 修改 + 以此种子重开）· 掉落倍率 · 经验倍率 · 图标/特效档位（沿用既有画质开关）

**F. 诊断（只读）**：FPS · 同屏敌人数 / 玩家子弹数 / 敌方子弹数 · **各对象池使用率（当前/上限）** · 当前难度档 · 种子 · 已进行时长 · 当前配装与已触发的血统/合体状态

### 4. 一键预设

| 预设 | 行为（**必须完整置入该状态，不能只改一半**） |
|---|---|
| **满级本系配装** | 该系 4 把武器置为满级；配齐该系 4 件被动；角色修正按当前角色 |
| **一键合体** | 先满足合体的**全部前置**（4 把满级 + 4 件指定被动 + **该系主动技已解锁**），再触发合体 |
| **解锁该系主动技** | 直接把该系主动技置为已解锁（**持久化语义**按改判规格 §4） |
| **跳到指定局内时间** | 设局内时间 → **重算难度档** → **立即按目标档位补一波怪** → **重置刷怪调度计时** → 若目标时间已过 Boss 触发点，则相应设置 Boss 状态 |
| **跳到 Boss 前** | 设为 Boss 触发前若干秒（同一套跳转语义） |
| **立即召唤 Boss** | 直接进入 Boss 阶段 |
| **无敌** | 开关 |
| **时间缩放** | 0.25× ~ 4× |

**跳转语义是硬要求**：只改时间数字而不补怪、不重算档位，会得到一个"时间是后期、场上是空的"的假状态——**那比没有这个按钮更糟**。

### 5. 配置串（内联契约）

**格式**：紧凑键值对，**不用 base64 JSON**（URL 要能被人读、也要短）。

```
# 版本前缀 + 分组键值，逗号/分号分隔
v1;seed=12345;t=540;ts=1;inv=1;
w=w_ult_shan:5,w_guhai:5,w_lizhao:5,w_shanbeng:5;
p=xuangui,kuiniu,shanyueji,dangkangya;
en=shanxiao*1.5,bifang*0,huashe*1,xinang*1,qiangliang*1;
spawn=2.0;hp=1.5;spd=1.0;elite=1.5;tier=-1;
```

| 键 | 含义 |
|---|---|
| `v1` | **版本号**（必需，用于兼容与拒绝非法配置） |
| `seed` / `t` / `ts` | 种子 / 局内时间 / 时间缩放 |
| `inv` | 无敌 |
| `w` / `p` | 武器槽（id:等级）/ 被动槽（id） |
| `en=<id>*<倍率>` | 每种敌人的数量倍率（`*0` = 关闭该种类） |
| `spawn` / `hp` / `spd` / `elite` / `tier` | 生成速率 / 生命 / 速度 / 精英频率 / 难度档（`-1` = 自动） |

- **导出**：一键把当前配置写成上述串，并生成完整 URL。
- **导入**：接受同格式串；**版本不匹配时拒绝并提示**，不猜测。
- **另外提供**："导出当前局状态"（完整的一局状态 JSON），用于把某个后期状态完整交给别人。

### 6. 守门（三条硬约束）

1. **正式包不得包含面板入口**：把"面板入口存在性"写进**静态检查**（沿用现有多条 guard 的同一套路），任何把面板带进正式包的改动都会检查失败。
2. **调参不写存档**：面板的所有改动都不得经过存档写入路径；**这条也要有检查或断言兜住**。
3. **面板不得联网**：沿用既有的"无网络请求"守卫。

### 7. 本次由规格代你决定的细节（**要改就说，别默认接受**）

1. **组合参数**：`?dev=` 支持逗号分隔的多个值（`ultimate,tune`）。
2. **真机快捷入口**：`dev` 非空时长按暂停键 2 秒开关面板。
3. **怪物开关粒度**：按**敌人 id**（5 种）+ 精英 + Boss，而不是按类型分组。
4. **诊断分组纳入面板**（FPS / 实体计数 / 池使用率 / tier / seed）——它不是"调参"但和调参同源，且直接服务性能预算。
5. **配置串用紧凑键值对**而不是 base64 JSON。

## Testing Decisions

**原则**：只测外部行为。

1. **正式包守门**：以正式构建跑静态检查，断言**不存在面板入口**（检查失败即为回归）。
2. **不写存档**：打开面板、随意改参数、关掉面板后，断言存档文件（最高分/图鉴/试炼/解锁/未完成的一局）**与操作前逐字节一致**。
3. **预设完整性**：
 - **一键满级**后该系 4 把武器均为满级、4 件被动齐备；
 - **一键合体**后**确实完成合体**（而不是"按了没反应"——它必须自动补齐"主动技已解锁"这个前置）；
 - **跳到指定时间**后：局内时间 = 目标值、难度档 = 目标档、**场上敌人数量 > 0**、刷怪调度器计时已重置。
4. **时间缩放**：把缩放设为 0.25× 与 4×，断言模拟推进速度成比例变化，且**判定与物理不失稳**（对比同种子下 1× 的结果差异在容差内）。
5. **敌人种类开关**：关掉全部远程敌人后，断言**场上不再出现远程敌人**（这是"没有弹幕时某系还行不行"这个测试的前提）。
6. **配置串往返**：导出 → 导入 → 导出，两次结果一致；**版本号不符时被拒绝且给出提示**（不得静默按错误的串配置）。
7. **触控不冲突**：面板展开时，摇杆触发区、闪避与主动技的命中区**仍然可正常触发**（或在面板覆盖处给出明确的例外行为）。
8. **面板不破坏既有玩法**：`?dev=tune` 打开但**不改任何参数**时，与不带该参数的一局在相同种子下**结果一致**。

---

## Out of Scope

- **不做玩家可见的作弊菜单**（面板只服务开发与测试，不面向玩家）
- **不做"面板里改存档/解锁真实进度"**（明确禁止写存档）
- 不改任何**正式玩法数值**（面板只改运行时的当前局）
- **不处理山魄/巫魄的主动攻击诉求**（本轮明确挂起，见 Further Notes）
- 不做联机 / 云配置同步 / 服务器端配置下发

## Further Notes

### 为什么这个工具比看起来更值钱

它解决的不只是"调参快"，而是**沟通成本**：现在你报一个现象，别人得自己复现；有了"配置进 URL + 导出局状态"，**一条 URL 就是一份可执行的问题描述**。这既是最准的复现手段，也是最省 token 的沟通方式——**一条 URL 顶一轮来回对话**。

### 挂起项（本轮明确不做，但要记着）

**"给山魄和巫魄加一些主动攻击"——你决定先不动。** 我没有把它丢掉，把它和诊断一起记在这里，方便以后随时捡起来：

- **山魄的真实缺口是结构性的**：六系里**只有山经的被动池一条进攻乘数都没有，也没有任何换算机制**（昆仑有"以守为攻"、灵山有"标记→诅咒"）。所以它后期乏力的原因不是武器白值，而是**没有成长曲线**。
- **巫魄的缺口是下限**：它的增伤依赖"目标已被标记"，而标记只由部分武器施加、只活 7 秒、**扩散只在敌人死亡时**——怪少或铺不开时增伤直接归零。
- 当时提出的三条不改按键的做法（**主动技两段式** / **被动池补乘数** / **角色固有"越近越强"**）依然有效，随时可以继续。
