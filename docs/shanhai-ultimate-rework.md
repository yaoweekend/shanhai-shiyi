- **交付**：批 1 = 六个主动技全部改完 + 开局三系终极；批 2 = 后三系终极（十日、百巫为性能风险点）。

## Problem Statement

我把"四合一终极武器"做完之后，一上手就发现一个很别扭的事：**终极武器和主动技能，是同一个东西的两种触发方式。**

- 终极武器是**自动**的、常驻的、以我为中心的一个圈，一直在掉血；
- 主动技能是**手动**的、按一下、以我为中心的一个圈，一次性掉血。

两个系统**看起来都在做同一件事**：以我为圆心的范围伤害。一个自动、一个手动，除此之外我说不出它们的区别——**所以我辛苦做的两套系统，玩起来像一套。**

更要命的是三件事：

1. **终极武器把"四"变成了"一"。** 山经原本四把武器是四种完全不同的手感（环绕旋刃 / 回旋骨镖 / 近身横扫 / 冲击场），合体之后只剩一个圆——**"四合一"实现成了"四变一"，它不再表达"我是山经"**。
2. **两个系统的解锁时刻几乎重合。** 该系技能要"3 把同系超武"，终极要"4 把满级 + 4 被动"，而终极要的那 4 件被动**恰好覆盖了 3 条血统所需的被动**——所以两个奖励在同一秒一起弹出来，在我心里它们**本来就是同一个奖励被拆成两份**。
3. **合体之后局内成长就断了。** 4 个武器槽占满、不能再拿新武器、技能也解锁完了，剩下的只有被动和升级数——**融合那一刻，玩法实际上收束了**。"终极之后不好玩"和"两个系统像"是同一个病的两个症状。

我要的不是"把特效做得更炫"，而是**让这两套系统在结构上就不可能被互换**。

## Solution

两条系统拿到**完全不同的职责**，并且**在时间轴上分开**：

- **终极武器 = 自动化火力的终点。** 它不需要我做任何操作，就该是"站着也赢"的爽感。而且它不再是一个换数值的圈——**每个系有一个全新的攻击机制，一眼就能看出这是哪个系**：
 · 山经「**不周崩**」——你走过的路会**裂开**，敌人被撕裂、被推离，裂缝塌陷造成爆发；
 · 海经「**归墟潮**」——不断推出**水环**，到最大半径后**回卷**，敌人被海浪**推着走**；
 · 大荒经「**赤地千里**」——一朵绕你公转的**雷云**，落雷跟着云走，形成一条移动的轰炸带，落点留下**焦痕**；
 · 天问「**十日凌空**」——身后浮现**十轮小太阳**，每轮持续射出一道金色光束扫射；
 · 灵山「**百巫夜行**」——召唤**巫影**，它们不打伤害，只上**蛊毒标记**，被标记者死亡时**爆毒雾并把标记传染出去**；
 · 昆仑「**昆仑永镇**」——身周**玉璧环**把**敌方子弹反弹回去变成己方弹幕**，同时回盾。
- **主动技 = 我唯一能主动施加的干预。** 伤害只是副产品，它的价值是**我做出的一个决定**：立岩挡怪（地形）/ 化潮穿怪位移（位移）/ 锁天钉住敌人（控场）/ **拉弓射巨箭（瞄准）** / 蛊爆引爆标记（处决）/ 不死药锁血（防御）。**没有一个是"再放一个圈"。**
- **解锁链串成一条不可乱的线**：本系武器满级 → 触发血统 → 集齐 3 个超武 → **解锁主动技** → 四满级 + 四被动 + **该系主动技已解锁** → **合体毕业**。两个里程碑因此**天然分两次到达**，而且顺手消灭了"融合先发生 → 技能永远解锁不了"这个脆弱依赖。
- **合体不是终点而是新起点**：终极武器自己可以继续升到 Lv5，每级变强，Lv3 与 Lv5 各有一个"质变点"。

## User Stories

1. As a **玩家**, I want 终极武器和主动技给我的感觉完全不同, so that 我花的注意力是两种不同的东西。
2. As a **玩家**, I want 终极武器不需要我操作就能持续输出, so that 它是"我变强了"的证明而不是又多一个要按的键。
3. As a **玩家**, I want 山经的终极是一条**跟着我移动的地裂**, so that 我不用看文字就知道它在奖励我往怪堆里冲。
4. As a **玩家**, I want 海经的终极是把敌人**推着走的水环**, so that 我能用"推挤"来处理我打不过的兽潮。
5. As a **玩家**, I want 大荒经的终极是**跟着雷云移动的轰炸带**, so that 我得考虑站哪、把敌人往哪引。
6. As a **玩家**, I want 天问的终极是**十轮小太阳环绕扫射**, so that 我一眼就知道自己在扮演"十日凌空"。
7. As a **玩家**, I want 灵山的终极是**只上标记、不打伤害的巫影**, so that 它靠"传染"而不是靠数值制造连锁。
8. As a **玩家**, I want 昆仑的终极能**把敌方子弹反弹成我的子弹**, so that 兽潮的弹幕反而变成我的武器。
9. As a **玩家**, I want 每个终极武器在**不按任何键**的情况下都能自己运转, so that 它符合"终极 = 不用操作"的承诺。
10. As a **玩家**, I want 终极武器能继续升级到 Lv5, so that 合体之后我还有东西可以攒。
11. As a **玩家**, I want 终极武器在 Lv3 和 Lv5 各有一个看得见的质变, so that "它在长大"这件事我能感觉到。
12. As a **玩家**, I want 合体之后拿到的东西明显比我交出去的四把满级武器更值, so that 我不会觉得自己亏了。
13. As a **玩家**, I want 合体后 HUD 明确告诉我"4 个槽都被这件事占满了", so that 我不会以为还能再拿武器。
14. As a **玩家**, I want 那几个被占掉的槽显示为纯金色而不是塞满小图标, so that 我不会误以为那三把武器还在工作。
15. As a **玩家**, I want 主动技是一个**需要我做的决定**, so that 按下去的时候我是在操作而不是在补输出。
16. As a **玩家**, I want 按下主动技能会**升起石壁把怪挡在外面**, so that 我能造出一个喘息的圈。
17. As a **玩家**, I want 按下主动技能能**穿怪位移**, so that 我能用它逃命或钻进怪堆。
18. As a **玩家**, I want 按下主动技能能**把一片敌人钉住**, so that 我能把危险区变成安全区。
19. As a **玩家**, I want 天魄的主动技是**像拉弓一样蓄力、可以改方向、射出一支金色巨箭**, so that 这一下是我瞄的、我选的时机。
20. As a **玩家**, I want 拉弓时**向后拖拽是拉弦、箭往反方向飞**, so that 手感符合拉弓的直觉、手指也不会挡住目标。
21. As a **玩家**, I want 拉弓时还能移动（只是变慢）, so that 我不会因为按技能而站在弹幕里等死。
22. As a **玩家**, I want 没蓄满就松手也会发射（只是弱一些）, so that 手滑不会让我白白浪费一次冷却。
23. As a **玩家**, I want 蓄满后箭会变亮、音效会变, so that 我知道"这一发是满的"。
24. As a **玩家**, I want 能把拉弓拖回按钮取消、并且不进冷却, so that 我可以"虚晃一枪"。
25. As a **玩家**, I want 按下主动技能能**引爆全场标记**, so that 我前面辛苦叠的标记终于有了回报。
26. As a **玩家**, I want 按下主动技能能**短时不会死亡**, so that 我有一条最后的保命线。
27. As a **玩家**, I want 每个系的主动技在**形状和用途上都不同**, so that 换系玩的时候操作感是换了一套,而不是换个数字。
28. As a **玩家**, I want 集齐 3 个同系超武时解锁主动技, so that 我拿到的是"操作工具"。
29. As a **玩家**, I want 合体要求"该系主动技已解锁", so that 两个里程碑分成两次到达，我有两次爽点。
30. As a **玩家**, I want 先解锁技能再合体之后技能依然能用, so that 我不会遇到"合体把我的技能吃掉了"。
31. As a **玩家**, I want 一个系可以在不同局里走"三超武拿技能"或"四合体毕业"两条路, so that 我有取舍。
32. As a **玩家**, I want 拉弓巨箭命中后**在原地炸出持续的日火**, so that 它和自动蓄力的那把武器感觉不同。
33. As a **实现者**, I want 五个术语（血统/超武/主动技/合体/终极武器）不再混用, so that 我不会再把三个不同的东西都叫"融合"。
34. As a **实现者**, I want 每个终极武器标明它的运行规则与"是否要求玩家移动", so that 我不会把一个需要移动的机制当成常驻场实现。
35. As a **实现者**, I want 一条"终极输出 ≥ 被消耗的四把满级武器总输出的 1.5 倍"的可验证标准, so that 我不需要靠手感判断平衡。
36. As a **实现者**, I want 明确的输入状态机（按下/蓄力/拖动/松手/取消）, so that 拉弓不会做成一个布尔标记。
37. As a **实现者**, I want 明确的性能风险点标注（十日光束、巫影传染链）, so that 我知道先压测哪两个。
38. As a **实现者**, I want 分批边界写清楚, so that 批 1 完成时后三系不会半途坏掉。
39. As a **实现者**, I want 记录下实现与总规格的槽位漂移（4武器/5被动 vs 3/4）, so that 我不会按错的那份改。
40. As a **维护者**, I want 反查手段：即使把终极武器全部禁用，六个主动技仍然彼此不同, so that 我能证明同质化真的被消除了。

## Implementation Decisions

### 0. 术语钉死（**不得再混用**）

| 术语 | 含义 | 归属 |
|---|---|---|
| **血统** | 单把武器满级 + 指定被动 → 该武器变超武形态 | 每系 4 条 |
| **超武** | 血统的产物（武器的一个状态，不是新武器） | — |
| **主动技** | 手动触发的"操作"，每系 1 个 | 6 个 |
| **合体** | 本系 4 把满级 + 4 被动 + **该系主动技已解锁** → 一把**全新机制的终极武器**，永久占满 4 个武器槽 | 每系 1 次/局 |
| **终极武器** | 合体的产物 | 6 把 |

**废弃"融合"这个词**：它此前同时指"血统"和"合体"，是混淆的源头。用户可见文案与新增注释一律用上表术语。

### 1. 职责分工原则（本次改判的核心）

- **终极武器 = 自动化火力**：不得要求任何玩家操作；在不按任何键的情况下必须持续产生效果。（**唯一例外**：山经的裂地要求玩家**移动**才产生效果——这属于"位置"而非"操作"，且它正是山经"贴脸冲阵"的身份表达，见 §2。）
- **主动技 = 玩家主动施加的干预**：位移 / 地形 / 控场 / 瞄准 / 处决 / 防御六类之一，**伤害只是副产品**，不得设计成"更大的一次范围伤害"。

### 2. 六个终极武器（全新机制）

通用：`locked: true`（不进卡池）、单把武器、占满 4 槽、**可升到 Lv5**、不吃"血统配方"。

| 系 | 终极 | 机制（全自动） | 运行规则要点 |
|---|---|---|---|
| 山经 | **不周崩 · 裂地** | 玩家**移动轨迹**上留下地裂段，段内敌人被撕裂并被推离；地裂到期**塌陷**造成范围爆发 | 轨迹按固定间距打点；**站着不动就没有输出**（这是刻意的：奖励冲阵）；推力方向 = 离开裂心 |
| 海经 | **归墟潮 · 潮汐** | 周期性推出**水环**，扩张到最大半径后**回卷收缩**；被扫过的敌人被沿环法向**推动** | 同一道环对同一敌人**只结算一次**；回卷阶段的推力方向相反 |
| 大荒经 | **赤地千里 · 天罚轮转** | 一朵**绕玩家公转的雷云**，落雷始终落在云下（移动轰炸带），落点留下**焦痕**持续灼烧 | 有预警圈；焦痕是独立区域，与雷击伤害分开计算 |
| 天问 | **十日凌空 · 十日** | 身后 **10 轮小太阳**绕玩家公转，每轮持续射出一道光束扫射；周期性**十日齐射** | 光束是持续判定（不是投射物）；齐射是短时爆发 |
| 灵山 | **百巫夜行 · 百巫** | 召唤若干**巫影**，**不造成直接伤害**，只给接触到的敌人上**蛊毒标记**；被标记者**死亡时爆毒雾并把标记传染** | 传染链**必须有层数上限**，防止无限递归 |
| 昆仑 | **昆仑永镇 · 玉璧** | 身周**自转的玉璧环**把**敌方子弹反弹**为己方子弹，同时持续为玩家回盾 | 反弹后的子弹归属玩家、伤害按倍率换算；环是视觉与判定一致的圆环 |

**升级（Lv1→Lv5）与质变点**：

| 终极 | 每级常规 | Lv3 质变 | Lv5 质变 |
|---|---|---|---|
| 裂地 | 伤害 / 裂宽 | 塌陷变为**牵引塌陷**（把敌人拉进坑） | **双裂缝并行** |
| 潮汐 | 环半径 / 频率 | **第二道外环**（内外交错） | 回卷带**拉拽**（把敌人拖向你） |
| 天罚轮转 | 落雷频率 / 焦痕强度 | 焦痕**扩散** | **双雷云反向公转** |
| 十日 | 单束伤害 | 太阳数增加 / 光束变粗 | **十日齐射**强化 |
| 百巫 | 巫影数量 / 标记时长 | 传染**范围扩大** | 被标记者死亡**分裂出新巫影**（有数量上限） |
| 玉璧 | 回盾速率 / 反弹倍率 | **第二层玉璧**（反向自转） | 反弹出的子弹变为**金色追踪弹** |

**平衡硬要求（可验证的验收标准）**：在标准兽潮与无操作（或固定路线移动）条件下，**终极武器的每秒输出必须 ≥ 被它替换掉的四把满级武器同条件总输出的 1.5 倍**。理由：合体是**不可逆的消耗**，玩家交出去的是四把满级武器，换回来的东西必须在数值上明显更赚，否则没人愿意合体。

### 3. HUD 与槽位表达

- 合体后：**1 格终极（显示等级与图标）+ 3 格纯金色锁定格**。
- **锁定格不绘制被合掉武器的微缩图标**——微缩图标会让玩家以为那三把还在工作，而事实是它们**已被消耗**；"合体是消耗"这个认知必须清晰（补偿靠 §2 的数值要求，不靠 UI 暗示）。
- 终极武器升到 Lv3 / Lv5 时，槽位格要有可见的等级与质变标记。

### 4. 解锁链（**不可乱的顺序**）

```
本系武器满级
   → 触发血统（满级 + 指定被动）→ 该武器成为超武
   → 集齐 3 个同系超武 → 解锁该系主动技
   → 本系 4 把满级 + 终极要求的 4 件被动 + 该系主动技已解锁 → 合体（毕业，占满 4 槽）
```

- **合体的前置条件必须显式包含"该系主动技已解锁"**。
- **主动技的解锁状态必须"达成即持久化"**，不得写成"每帧从武器槽里数超武数量"——因为合体会把 4 把武器塌缩成 1 把，那种写法在合体后必然失效（这是一个已经存在的脆弱依赖，本次一并消灭）。
- 主动技解锁后**跨合体保持可用**。

### 5. 六个主动技（操作，不是伤害）

| 系 | 主动技 | 类型 | 效果 | cd |
|---|---|---|---|---|
| 山经 | **立岩** | 地形 | 以你为中心升起环形石壁，持续数秒：圈内敌人被**持续推向外侧**并受伤（玩家在圈内相对安全） | 14s |
| 海经 | **化潮** | 位移 | 沿摇杆方向**穿怪位移**一段距离，路径上的敌人受伤并被推开，位移瞬间**免疫伤害** | 10s |
| 大荒经 | **锁天** | 控场 | 一片范围内的敌人被**钉住**数秒（精英同样生效；**Boss 改为强减速**而不是完全定身） | 15s |
| 天问 | **拉弓巨箭** | 瞄准 | 见 §6 状态机 | 11s |
| 灵山 | **蛊爆** | 处决 | **引爆全场所有蛊毒标记**：每个被标记者独立结算伤害并短暂眩晕（标记越多越强；未标记者不受影响） | 12s |
| 昆仑 | **不死药** | 防御 | 数秒内**不会死亡**（血量锁在最低值，受到的伤害优先消耗护盾），并立即回复护盾 | 18s |

- **输入模型**：允许每系定制手势，但**手势种类上限 4 种**（点按 / 按住蓄力 + 拖动瞄准 / 按住范围指示 + 松手 / 按住持续引导）。**批 1 只有天问（拉弓）使用非点按手势**，其余五系先点按，留出升级空间。
- 主动技的冷却从**生效或取消**起算；取消不进冷却。

### 6. 天问「拉弓巨箭」输入状态机（内联契约）

**状态**：`待机` → `蓄力中`（按下）→ `瞄准中`（拖动）→ `发射`（松手）/ `取消`（拖回）→ `冷却`

| 项 | 规则 |
|---|---|
| 进入条件 | 按下右下主动技能键区域；该系主动技已解锁；冷却为 0 |
| 蓄力 | 按住时长 `t` 累积，满蓄 `T=1.2s`，比例 `c = min(1, t/T)` |
| 方向 | 记录按下点 `p0` 与当前手指点 `p1`，**方向 = normalize(p0 − p1)**（**反向拖拽 = 拉弦，箭向反方向飞**）；拖动距离小于阈值时，方向取玩家当前朝向 |
| 移动 | **蓄力期间可自由移动，但移速 ×0.7**（这是刻意留的代价：在兽潮里拉弓要有风险，否则它又变回"免费输出"） |
| 发射 | 松手即发射（**未满蓄也发射**）：伤害随 `c` 缩放；箭体宽度随 `c` 变宽；**贯穿全场**；命中点在**原地留下持续灼烧的"日火"区域** |
| 满蓄提示 | `c=1` 时箭光变亮 + 音效上扬 + 准星变金（必须是不看 UI 也能察觉的反馈） |
| 取消 | 手指拖回按下点附近再松手 = 取消，**不进冷却** |
| 冷却 | 从发射起算；取消不计 |
| 表现 | 命中时屏幕震动 + 金色粒子；日火区域与已有的"灼烧"表现区分开 |

### 7. 与既有武器的边界（防止新的同质化）

- 天问系第 4 把武器「**天极贯日**」是**自动蓄力贯穿**武器。它与拉弓巨箭的**唯一合法区分**是：**方向由谁决定**（武器自动瞄准 / 技能由玩家拉弓瞄准），**外加量级与后续影响**（技能更大、并且命中后留下日火区域）。
- **保留回退方案**：如果实机手感测试后仍然觉得两者相似，则**改掉「天极贯日」的机制**（换成别的自动攻击方式）并把"蓄力贯穿"完整让给主动技，同时改它对应的血统配方文案。
- 同理，终极武器的六个机制都已核对过**不与本系已有的四把武器重合**（尤其注意：昆仑的终极是"反弹敌方子弹"，全作此前没有任何武器能利用敌方子弹，这是区分度最高的一个）。

### 8. 分批交付

| 批次 | 内容 | 验收 |
|---|---|---|
| **批 1** | **六个主动技全部改成"操作"**（含天问拉弓的完整输入状态机）＋ **终极武器：开局三系（裂地 / 潮汐 / 天罚轮转）** ＋ 解锁链（含"技能已解锁"前置与持久化）＋ HUD 表达 ＋ 术语重命名 | 通过 §Testing 的 1–9 项 |

### 9. 已观察到的实现漂移（**以实现为准**）

总规格写的是"武器槽 3 + 被动槽 4"，但**实现里是武器槽 4 + 被动槽 5**，且武器满级为 **Lv5**。本增补的验收标准**一律按实现值（4 / 5 / Lv5）计算**，并在此记录这次漂移，避免后人按错的一份改。

## Testing Decisions

**原则**：只测外部行为（给定输入，游戏状态与可见结果是什么），不断言内部函数组织方式。

1. **合体条件**：4 把同系满级 + 4 件指定被动 + **该系主动技已解锁** → 合体成功；**缺少"技能已解锁"这一条时必须不合体**（这是本次新增的硬前置，必须有断言）。
2. **技能持久化（回归那个脆弱依赖）**：先解锁主动技 → 再合体 → **主动技仍可用、仍能触发**。
3. **终极不是"换数值的圈"**：**断言六个终极的机制两两不同**——至少覆盖"轨迹型 / 往返环 / 移动轰炸带 / 多光源扫射 / 传染型随从 / 反弹型护盾"六类，且**不存在两个终极共用同一套判定形状**。
4. **无操作也能运转**：除裂地外，每个终极在**玩家不做任何输入**的情况下都必须持续产生输出；裂地的断言改为"玩家沿固定路线移动时产生地裂与塌陷"。
5. **平衡硬要求**：标准兽潮条件下，终极武器每秒输出 ≥ 被替换的四把满级武器同条件总输出的 **1.5 倍**（用固定种子与固定场景可复现）。
6. **六个主动技彼此不可互换**：断言"任意两个技能所属的类型不同"（位移 / 地形 / 控场 / 瞄准 / 处决 / 防御各一个），且**没有任何一个技能是纯范围伤害**。
7. **拉弓状态机**：按下 → 蓄力 → 反向拖动 → 松手，**箭的方向 = 拖动方向的反方向**；未满蓄松手**也发射**；拖回取消**不进冷却**；蓄力期间移速 = 基准的 0.7；满蓄有可见/可听的反馈。
8. **HUD**：合体后 1 格终极 + **3 格纯金色锁定**（不得出现被合掉武器的微缩图标）；终极 Lv3 / Lv5 的质变在 HUD 上可见。
9. **术语**：用户可见文案中**不得残留把"合体"称作"融合"**的表述；三个不同的东西（血统 / 合体 / 主动技）不得共用同一个词。
10. **性能**：十日（10 道持续光束）与巫影（多随从 + 传染链）在**300 敌人**的压测场景下不超预算；**对象池计数长期运行不得增长**。
11. **反向检验（证明同质化真的被消除）**：禁用全部终极武器后，六个主动技仍然彼此不同；禁用全部主动技后，六个终极仍然彼此不同。

**先例**：本项目的既有测试组织方式（`test/all.mjs` 编排多套件）；无头单局模拟与固定种子复现的思路可沿用。

## Further Notes

### 这是对总规格的明确改判

总规格在 `specs/shanhai-survivors.md` 里把主动技定义为"按系各自设计（效果各异）"的**六个范围伤害**。本次改判为：**主动技 = 操作（位移/地形/控场/瞄准/处决/防御），伤害只是副产品**；并把终极武器从"同一机制换数值"改为"每系一个全新机制"。写下改判的原因，是为了让后人知道这不是漏写，而是刻意改的。

### 同质化的三层诊断（证据）

1. **几何同质**：六个终极与六个技能全部作用于"以玩家为圆心"的圆。
2. **职责同质**：两者都只提供范围伤害，**都不提供"操作"**。
3. **身份同质**：合体把四把不同弹道的武器塌缩成一把，**删掉了本系的多样性**。

配套的两个结构性问题：**解锁时刻重合**（终极要求的 4 件被动覆盖了 3 条血统所需的被动）与**合体后局内成长收束**（槽位占满、技能解锁完）。

### 落笔前发现并修正的两处冲突

1. **昆仑的"玉璧"在终极与主动技上重名**：昆仑的终极武器定为"玉璧环（反弹敌方子弹）"，而原先给昆仑主动技的方向也是"玉璧（无敌 + 回盾）"。**已改**：昆仑主动技更名为「**不死药**」（短时不会死亡 + 回满护盾），与终端的"反弹弹幕"在机制与命名上都分开。
2. **山经「立岩」的实现成本**：原方向是"升起一圈不可穿越的岩障"，那需要引入障碍碰撞与敌人绕行。**已简化为"持续的推力场 + 触碰伤害"**：视觉上仍是石壁、玩家在圈内相对安全，但底层只是一圈推力与伤害判定，不需要寻路或静态碰撞改造。**玩家的体验目标（造一个喘息的圈）不变，成本降一个量级。**

本增补 §0 的五个术语应同步进项目根目录的 `CONTEXT.md`（术语表只放词汇，不放实现）。**本工作区只产规格、不落实现**，因此以本文件为准交给实现会话执行。

### 批 2 落地记录（2026-10，实现会话回填）

批 2 交付了后三系终极（**十日凌空 · sunwheel / 百巫夜行 · plague / 昆仑永镇 · bulwark**），
过程中对两处"规格张力"做了**必须记一笔**的定案，避免后人以为漏做：

1. **百巫的"1.5× 输出"归因（口径：可量化，因此不申请豁免）**
   - **巫影的直接伤害恒为 0**（`minion.damage = 0`，测试里有硬断言）—— 这一条严格遵守。
   - 百巫的产出被落在**标记自己身上**：「蛊毒标记」本身就是毒（被标记者持续掉血），
     被标记者死亡时**爆毒雾**（独立的持续伤害区域）并**把蛊毒传染**给附近敌人。
     三者都不是"巫影打出来的伤害"，所以"不造成直接伤害"没有被破坏。
   - 标记原有的**放大器语义（每层 +12% 受伤，最多 3 层）保留**，其带来的伤害增量单独记进
     `world.runStats.markAmpDamage`，作为归因佐证（测试断言它 > 0）。
   - **副作用（刻意）**：百巫不再需要"别的来源先杀人"才能启动 —— 否则合体后玩家手里只剩它，
     会陷入"没人能杀 → 永远没有毒雾 → 输出恒为 0"的死锁（这是本次实测发现的）。
2. **平衡场景必须含**会开火的敌人**（玉璧的前提），且**不能再用"全钉死的高血量靶场"**
   - 玉璧的产出全部来自**反弹敌方子弹**：纯近战兽潮下它的输出**恒为 0**，这是它的身份，不是漏做。
   - 百巫的死亡毒雾需要**真实发生的击杀**：批 1 那种"血量 1e6 且每帧抬满"的靶场永远不会有人死，
     用它量百巫等于用错误的尺子（实测恒为 0）。
   - 因此批 2 的平衡口径改为：**标准兽潮（120 近战 + 60 毕方，tier 4 血量 300）+ 击杀即时补位
     + 固定圆周路线 + 固定种子 20260926**，四把满级基线与终极在同一场景下对比。
     批 1 三系的验收仍保留其原有的靶场口径（`test/batch1-rework.mjs` 第 5 节未改）。
   - 实测倍率（Lv1 / Lv5）：十日 1.91×/3.81×，百巫 2.33×/9.45×，玉璧 3.17×/12.65×。
